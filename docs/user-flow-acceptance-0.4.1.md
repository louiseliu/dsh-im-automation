# 0.4.1 普通用户流程复验

环境：官方 DeepSeek Harness 0.2.1-rc.5 桌面版、dsh-im 5.9.1、本插件 0.4.1。仅安装本插件，没有修改 Harness 或 dsh-im。

本次是按普通用户操作路径进行的开发验收，不是独立用户盲测。

## 四项改动

1. 机器人显示公开账号名称；接收位置使用可确认的名称。平台不提供姓名时，要求填写一次备注，并持久保存。备注与实际路由绑定，路由改变后不会沿用旧备注。
2. 根据机器人已绑定会话所在目录自动匹配唯一工作区。匹配明确时隐藏目录选择，保留“更换工作区”；不明确时仍要求选择。
3. 创建后显示已保存、等待首次执行、准确执行时间、发送对象及记录归属。首次执行前禁用查看记录，避免进入空白欢迎页。执行中、发送中、成功、失败和待核查分别反馈。
4. 首页直接展示最近完成的五项任务及结果时间，更早记录折叠。一次性任务触发后，在 AI 完成前仍显示在进行中。
